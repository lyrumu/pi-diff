# 暂缓功能设计

日期：2026-10-14。用户决定先完成简单改进，复杂功能先留文档。本文件是后续设计与验收边界，不表示已实现，也不授权自动迁移会话数据。

## 1. 旧会话历史恢复

### 已确认的问题

本机「阶段1」会话有 80 条旧 diff entry：customType 错误地嵌套了整个对象，turn 全为 0，patches 全为空。PLAN.md 的两次 edit 成功，工具结果仍有 diff 片段，但旧 diff entry 没有保存改动内容。

本期只增加可用性提示：旧记录不可用与有效空轮次分开；部分历史损坏时，会话累计明确标记历史不完整。不会改写原始会话，也不会把当前工作副本当作历史。

### 第一性原理

历史 diff 必须来自当时的证据。当前文件内容或当前 Git diff 无法证明某一旧轮次的前后状态。修正 entry 外形不能恢复空 patches，也不能把 80 次旧 turn_end 调用解释成 80 个用户轮次。

### 后续最小方案

1. 只读遍历指定会话的父子链，确定用户任务边界，保持不同分支独立。
2. 对 edit 收集成功的工具结果 diff 和 oldText/newText；write 若只有新内容而没有旧侧，标记只能部分恢复；bash 文字输出不能直接当作可靠文件快照。
3. 同一文件多个工具调用需要按执行顺序组合，证明两端连续性；失败、并发、截断、外部修改或缺失旧侧时，不声明完整恢复。
4. 优先生成独立、可审阅的恢复报告；以后若提供导入，先备份，使用新 customType/来源标记，不覆盖原 entry、不伪造正常捕获轮次，导入须另行确认。

### 验收与对抗性审查

- 分支切换不串历史；同一轮多次 edit 不重复计数。
- 失败工具、截断输出、缺少旧侧、write 覆盖和交错调用都明确降级。
- 恢复结果不能影响正常新轮次编号；报告可重复生成，无副作用。
- 不请求模型猜测历史，不用当前磁盘填补旧状态。

## 2. 项目外文件追踪

### 当前边界与上游参考

Tracker.normalize 拒绝 cwd 之外的文件。opencode Snapshot.capture 也基于当前 Location 的项目/目录捕获；并没有扫描整个用户目录的保证。

本期维持现有边界。后续如支持外部文件，应扩展所有已知目标使用的同一个 recordFileChange 入口，不增加旁路扫描器。

### 后续最小方案

- 先仅支持 edit/write 明确给出的外部目标，在执行前捕获旧侧，轮次结束读取新侧。
- 文件身份需能无歧义地区分项目内与外部绝对路径；明确处理 `~`、相对路径、符号链接和会话启动目录变化，避免路径重名。
- TUI 使用「项目外文件」分组，外部文件只进入每轮和会话累计；Git 范围仍限制在当前仓库。
- 相同文件多个工具修改、读取失败、删除/重建、10MB 上限、缓存与历史重放继续使用现有语义；不能因另一仓库有 HEAD 就冒充本轮旧侧。
- bash 任意修改外部路径不保证捕获。不要用命令文本猜测所有目标，不扫描整个 home/磁盘；若以后支持额外根目录，需要用户明确指定范围。

### 验收与对抗性审查

- 两个不同目录的同名文件不合并；外部新增、修改、删除的已知旧侧准确。
- Git 项目中修改另一个仓库或非 Git 目录，仍以工具执行前内容为旧侧。
- 历史自包含、分支重放正确，外部文件不可读时不冒充删除。
- 不增加全盘扫描、后台监控或系统配置写入。

## 3. 其他暂缓交互

继续保留一期偏离：改动块跳转、连续展示多个文件、已审阅标记、手动选择 Git 基准、图片预览、字符级高亮。鼠标拖选/复制、右键菜单和文件搜索尚未实现。

这些功能分别参考 opencode 的 diff.next_hunk、diff.single_patch、diff.mark_reviewed、基准选择与图片组件；需要独立需求和验收，不与基础滚轮/点击合并实现。

原生触控板横滑不再作为当前需求：用户于 2026-10-15 确认默认自动换行，已删除横移状态、Shift+滚轮横移和左右按钮。普通/Shift+滚轮均用于纵向滚动。pi 宿主未传递原生横向方向的限制仍存在，但不需要为此修改宿主或新建全局鼠标解析。

| 优先级 | 功能与上游来源 | 适用价值与实施边界 |
|---|---|---|
| 高 | 改动块跳转：`diff-viewer.tsx` 的 jumpRelativeHunk、`[`/`]` | Git 的 12 行上下文可能形成多个 hunk，可减少滚动；用现有解析结果与视觉行索引定位。会话 diff 使用全文件上下文，通常只有一个 hunk，如需逐处跳转还需明确是否按增删片段分组；不把任意虚拟块边界当作改动块 |
